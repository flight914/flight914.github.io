# Flight914.github.io — 한국어 독립 영화 가이드

Flight 914로 표시되는 온라인 판본 및 카탈로그명 **Flight World War II / Flight 1942**에 관한 독립 리뷰 웹사이트입니다. 기본 HTML/CSS/JS로 구성된 정적 사이트입니다.

## 포함된 항목

- `index.html`: 3,000개가 넘는 한국어 공백 구분 어절의 본문, H1–H3 구조, 영화 정보 표, 직접 조작하는 이미지 슬라이더, 스포일러 토글, FAQ, 출처 링크 및 창작 모션 그래픽 비디오.
- `about.html`, `contact.html`, `content-policy.html`, `privacy.html`, `disclaimer.html`, `dmca.html`, `terms.html`: 정보·정책 페이지.
- `assets/images/`: 이 사이트용으로 생성한 독립 콘셉트 이미지. 영화 스틸이나 공식 포스터가 아닙니다.
- `media/flight914-explainer.ko.mp4`: 18초 한국어 자막 모션 그래픽. 원본 영화 장면·대사·음악이 없습니다.
- `robots.txt`, `sitemap.xml`, `404.html`, `.nojekyll`: GitHub Pages용 정적 사이트 파일.

## GitHub Pages 게시

요청한 주소는 `https://flight914.github.io/` 입니다. GitHub Pages의 사용자 사이트 주소가 되려면 소유자가 GitHub 계정 **Flight914**를 관리하고, 그 계정에 이름이 정확히 `Flight914.github.io`인 저장소를 만들어야 합니다. 2026-11-15에 확인했을 때 해당 주소와 공개 저장소는 아직 404였습니다. 아직 외부에 배포되지 않았습니다.

1. `Flight914` GitHub 계정에 로그인합니다. 계정 이름을 사용할 권한이 있는지 확인하세요.
2. 공개 저장소 이름을 `Flight914.github.io`로 만들고 이 폴더의 내용을 저장소 루트에 업로드합니다.
3. 저장소의 **Settings → Pages**에서 배포 소스를 기본 브랜치의 루트로 설정합니다.
4. 게시 완료 후 `https://flight914.github.io/` 및 각 정책 페이지, 영상·자막 파일을 확인합니다. 이 GitHub 기본 주소에는 `CNAME` 파일이 필요하지 않습니다.
5. 저장소에 Issues를 켜면 문의 페이지의 저장소 링크를 사용할 수 있습니다. 실제로 관리하는 문의 이메일을 공개하기로 했다면 `contact.html`, `privacy.html`, `dmca.html`을 함께 갱신하세요.

## 공개 전 확인 사항

- 제목·개봉연도·감독·출연진 정보는 Apple TV 및 Rotten Tomatoes 링크로 교차 확인했습니다. 제공 지역과 판본에 따라 표기가 달라질 수 있습니다.
- `Flight 914`는 해당 온라인 판본에서 보이는 표기입니다. 사이트는 이를 공식 배급 제목이라고 단정하지 않으며 독립 리뷰임을 밝힙니다.
- 사이트에는 원본 영화 영상·음악·자막·포스터를 넣지 않았습니다. 영상은 생성된 콘셉트 아트와 자체 문구만 사용한 무음 모션 그래픽입니다.
- 사이트는 현재 광고, Analytics, 쿠키, 제3자 플레이어를 사용하지 않습니다. 추후 추가하면 개인정보 처리방침과 지역별 동의 요건을 먼저 검토하세요.
- GitHub 저장소에 문의 이메일을 적기 전 실제로 관리하는 주소를 확인하세요. 아무 이메일 주소도 임의로 만들지 않았습니다.
- 독립 이미지, 텍스트, 비공식성 및 저작권 요청 절차를 `MEDIA-NOTES.txt`에서 확인하세요.
